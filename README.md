# SIGNAL – Download

**[⬇ Neueste Version herunterladen](https://github.com/SignaloRoberto/signal-releases/releases/latest)** → `SIGNAL-Setup-x.y.z.exe`

1. Herunterladen und starten. Windows warnt evtl. („Unbekannter Herausgeber“) → *Weitere Informationen* → *Trotzdem ausführen*.
2. SIGNAL installiert sich und startet. Updates kommen danach automatisch.
3. „Netz beitreten“ → Code vom Host eingeben.
